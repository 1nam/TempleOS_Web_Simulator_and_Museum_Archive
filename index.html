1969 — BORN IN WEST ALLIS, WISCONSIN

Terrence Andrew Davis (Dec 15, 1969 – Aug 11, 2018) grew up around computers, programming on a Commodore 64 and later earning a master's degree in electrical engineering from Arizona State University. He worked on Ticketmaster's VAX operating systems before beginning the project that would consume his life.

WHY IT MATTERS

TempleOS is studied today as an extreme case study: a complete modern 64-bit OS — compiler, kernel, graphics, filesystem (RedSea), games, hymns and a 3-D flight demo — built outside every modern convention, by one programmer living with schizophrenia. This archive preserves the ideas, the interface language, and the oracle mechanic in playable form.

HOLYC — SOURCE + DEPLOY

In TempleOS the shell is HolyC. Code is JIT-compiled and run instantly:

// GodBits.HC — oracle in the spirit of the original
U0 GodWords(I64 seed)
{
  I64 i, n = 5 + (Abs(seed) % 6); // 5..10 words
  Seed(seed); // millisecond of YOUR keypress
  for (i=0; i<n; i++)
    Print("%s ", KJV[RandU16 % KJV_COUNT]);
  "\nGod loves you.\n";
}
GodWords(NowMs); // <-- run it. Ring-0. No permission asked.
