# 🏛️ TempleOS Web Simulator & Museum Archive

A lightweight, single-file static web museum and simulator dedicated to preserving the programming legacy and unique architecture of Terry A. Davis's **TempleOS**. 

This project aims to introduce new programmers to the raw, solo engineering feat of a 100,000+ line operating system built entirely from scratch, stripped of modern abstractions.

## 🚀 Live Demo
*https://1nam.github.io/TempleOS_Web_Simulator_and_Museum_Archive/*

## 🎨 Features
- **Authentic 16-Color UI:** Built inside a rigid, 4:3 viewport matching Terry's historical 640x480 resolution constraints. No rounded corners, no soft gradients—just pure retro computing.
- **The "God Words" Oracle:** A functioning JavaScript engine that taps into millisecond keystroke entropy to pull random words from a local text bank, simulating the original TempleOS prophet widget.
- **Retro Canvas Game:** A primitive, client-side mini-game styled after Terry's 16-color vector-drawn simulations.
- **Terminal Simulator:** An interactive command window to let users explore basic file directory inputs (`Dir;`, `Help;`) framed in simulated HolyC code styles.

## 🛠️ How to Run Locally
Because this entire project is bundled into a single, static file, it has **zero dependencies** and requires no server configuration:
1. Download or clone this repository.
2. Double-click `index.html`.
3. It will instantly run natively inside any modern web browser (Chrome, Firefox, Safari, Edge).
